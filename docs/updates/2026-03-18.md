## Clarification: Batch-Size-Aware Cap

For any class/group cap in structured selection, cap should scale with structured batch budget:

1. `B_struct = round(B * p_structured)`
2. `max_per_class = max(1, ceil(rho * B_struct))`
3. default `rho = 0.4`

This avoids fixed-cap underflow when `B` increases and keeps enough room to pick high `d_head + d_action` samples.
